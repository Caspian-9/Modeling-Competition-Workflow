# 数学建模图书管理员检索源与证据分级

## 检索顺序

按“原始权威事实 → 学术证据 → 可复用实现与数据 → 线索来源”检索。一个网站可能同时
承担多类用途，证据等级取决于具体文档，而不是网站名称。

### A：原始权威来源

- 题目涉及机构的官网、公开数据库、技术规范、统计公报和数据字典。
- 中国政府网、国家统计局“国家数据”、各部委和行业监管机构、地方统计局。
- 全国标准信息公共服务平台、国家法律法规数据库、国家知识产权局。
- 国际组织与公共机构：WHO、World Bank、UN Data、OECD、IMF、FAO、ILO。
- 专业领域数据：国家气象科学数据中心、国家地球系统科学数据中心、天地图、NASA
  Earthdata、NOAA、Copernicus、OpenStreetMap。

用途：定义、单位、约束、政策、基准统计、官方数据和标准。记录发布机构、版本、更新
日期、数据口径与许可证。

### B：经过同行评议或可核验的学术来源

- 中文：CNKI（知网）、万方、维普、国家哲学社会科学文献中心、SinoMed。
- 综合索引：Web of Science、Scopus、Google Scholar、Semantic Scholar、OpenAlex、
  Crossref、BASE、CORE、DOAJ。
- 学科库：PubMed、IEEE Xplore、ACM Digital Library、RePEc、SSRN，以及出版社页面。
- 预印本：arXiv、bioRxiv、medRxiv、ChinaXiv；必须显式标注“未同行评议”。
- 引文网络：Connected Papers、ResearchRabbit、Lens；只用于发现，回到原文核验。

用途：机制、方法、既有比较、参数范围与已知局限。优先系统综述、领域综述、与当前分析
单位和数据生成机制接近的研究。无法访问全文时标注“摘要/元数据级”，不得补写正文结论。

### C：代码、数据与可复现材料

- GitHub、GitLab、Gitee；Papers with Code 用于论文—代码映射。
- Zenodo、Figshare、OSF、Dryad、Mendeley Data。
- Kaggle、UCI Machine Learning Repository、OpenML、Hugging Face Datasets。
- 国内开放数据平台及高校、科研院所的数据仓库。

用途：接口设计、算法实现、测试数据和复现线索。必须核验许可证、固定 commit/tag、依赖、
测试、维护状态、数据口径与泄漏风险。Star 数和排行榜成绩不是证据，不得在本角色执行未知
代码。

### D：行业与社区线索

- 行业协会、企业技术白皮书、咨询报告；披露商业利益和方法不透明性。
- Cross Validated、Operations Research Stack Exchange、Stack Overflow、专业论坛和博客。
- 百度学术可用于中文线索发现，但应回到原始出版物或数据库页面核验。

用途：术语、实践问题、故障模式和进一步关键词。不能单独支撑关键事实或最终方法主张。

## 竞赛专项来源

- 全国大学生数学建模竞赛官网及官方赛题、规则、获奖名单和公开评阅材料。
- 高校数学建模中心、公开优秀论文档案和赛后复盘。
- GitHub/Gitee 上的历史赛题实现。

在 `active_competition` 模式下，只用官方规则和历年公开材料作通用规范与方法先例；禁止
搜索、收集或借用当前赛题的团队解答、泄露材料和同题代码。在 `retrospective` 模式下可检索
历史同题实现，但必须标记“同题污染”，不能把它当作独立验证或原创性证据。

## 证据等级

- `A`：可追溯的官方原始数据、标准、法规或一手技术文档。
- `B1`：同行评议的系统综述、权威指南或高相关多研究综合。
- `B2`：同行评议且与当前问题高度相关的单项研究。
- `C1`：可核验的预印本、学位论文、会议材料或透明技术报告。
- `C2`：有许可证、版本和复现信息的代码或数据仓库。
- `D`：白皮书、博客、问答、聚合页或仅能核验摘要/元数据的线索。

等级不自动决定是否采用。过时、口径不符、样本不匹配或利益冲突会降低可迁移性；与当前
问题高度匹配的透明 C2 实现也只能证明“可参考实现”，不能证明模型有效。

## 最低来源记录

每条来源至少记录：稳定 ID、标题、作者/机构、年份、URL、DOI/持久标识、访问日期、访问
深度、证据等级、对应 requirement ID、相关结论、局限、许可证（适用时）和核验状态。

每条检索至少记录：网站/索引、原始查询式、时间、可见结果数（若有）、筛选理由和访问
障碍。知网等需要登录、订阅或验证码时，不绕过访问控制；记录元数据，或请求用户提供合法
导出的 RIS/BibTeX/PDF 后再核验。
